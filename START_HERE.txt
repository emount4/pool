БАССЕЙН — ГОТОВАЯ СБОРКА 2.0.0

1. Установите Java 21 (64 бита) и Docker Desktop.
2. Полностью распакуйте этот архив.
3. Запустите Docker Desktop и дождитесь готовности.
4. Windows: откройте start.bat.
   Linux / macOS: выполните ./start.sh в терминале.
   Если нужно: chmod +x start.sh run.sh mvnw
5. Вход администратора: admin / Admin123
   Вход оператора: operator1 / Operator123

Maven и отдельная установка JavaFX для готовой сборки не нужны.
При первом запуске Docker скачает PostgreSQL из интернета.

Если база уже запущена, используйте run.bat или ./run.sh.
Если у вас своя база КР №1, настройте database.properties.
Не запускайте schema.sql и data.sql поверх существующих данных.

README.md — полная инструкция и решение проблем.
docs/REQUIREMENTS.md — соответствие ТЗ и сценарий защиты.
docs/TEST_REPORT.md — результаты и ограничения проверок.
docs/screenshots/ — снимки интерфейса.
src/ и pom.xml — полный исходный проект Maven.
database/ — SQL и начальные данные.
app/ — собранный клиент и все его библиотеки.

Собственные данные сохраняются в Docker volume после остановки.
Остановка: docker compose down
Не добавляйте -v, если нужно сохранить данные.
