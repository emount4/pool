## Сценарий демонстрации (7–10 минут)

1. Запустить `start.bat` / `start.sh`, показать готовность контейнера, войти как `admin`.
2. Открыть «Клиенты», создать нового клиента. Попробовать пустое имя, будущую дату рождения и повторный телефон — увидеть ошибки.
3. Исправить значения, сохранить клиента. Найти его по части фамилии и телефона; проверить два фильтра и сортировку.
4. Изменить контакты клиента, показать сохранение после обновления.
5. Открыть «Посещения», создать запись на завтра. Выбрать клиента из списка, свободный интервал и дорожку.
6. Перенести будущий сеанс. Показать, что занятое время или дорожка недоступны.
7. Найти посещение по клиенту, применить статус, дорожку и период. Отсортировать по дате и времени.
8. Экспортировать текущую таблицу в XLSX и CSV, открыть файл: в нём только показанные строки.
9. Показать статистику, период и диаграмму. Экспортировать показатели.
10. Отменить будущую запись: статус изменяется, время освобождается. Удалить запись с подтверждением, затем удалить созданного клиента.
11. Создать оператора / изменить доступ. Выйти и войти как оператор: вкладки управления пользователями нет.
12. Остановить и повторно запустить проект, показать сохранение данных.

## Что объяснить на защите

- `Main` — точка входа, `AppContext` собирает зависимости.
- FXMLLoader связывает элементы с полями контроллера по `fx:id`; `onAction` вызывает обработчик.
- Контроллер получает данные формы, сервис проверяет правила, DAO выполняет параметризованный SQL.
- Коллекции JavaFX обновляют таблицы; после сохранения выполняется повторное чтение из БД.
- Фильтры комбинируются через логическое И, сортировка работает с типизированными столбцами.
- `FxTasks` выполняет JDBC и экспорт в отдельном потоке; UI обновляется на JavaFX Application Thread.
- Правила пересечений учитывают полуоткрытые интервалы `[начало, конец)`: 10:00–11:00 и 11:00–12:00 совместимы.
- EXCLUDE-ограничения БД страхуют конкурентные записи, сервис даёт понятные сообщения заранее.
- CSV корректно экранирует кавычки/переносы строк, сохраняет кириллицу и нейтрализует формулы.
- Docker запускает БД; JavaFX работает на хосте и подключается к опубликованному порту.
