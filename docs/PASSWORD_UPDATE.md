# Обновление: показ пароля и предупреждения VS Code

11 октября 2026 года добавлена кнопка «Показать / Скрыть» справа от поля
пароля на экране входа. При создании первого администратора она также
переключает видимость подтверждения пароля. По умолчанию пароль скрыт;
после попытки входа поля очищаются и показ отключается.

Исправлены два предупреждения со скриншота:

- `VisitMenu.java`: `new Locale("ru")` заменён на `Locale.of("ru")`.
- `JdbcIntegrationTest.java`: удалён неиспользуемый импорт `java.sql.*`.

Полный прогон: 25 тестов, 0 ошибок, 0 неуспешных, 0 пропущенных.
Отчёты находятся в `docs/test-results/password-update/`.
Проверена загрузка всех 9 FXML, переключение видимости, редактирование
пароля в открытом виде, сохранение ввода после скрытия, очистка обоих
полей, JDBC и сохранение клиента/посещения через формы.

Условия тестирования: Linux x64, JDK 21, JavaFX/Monocle, временная база
PostgreSQL/PGlite. Нативный запуск Windows проверяется на компьютере
пользователя. Зависимости и параметры подключения не изменены.

## Установка обновления поверх готовой сборки

1. Закройте окно приложения «Бассейн».
2. Распакуйте `pool-desktop-update-1.zip` в отдельную папку.
3. Скопируйте из неё папки `app`, `src` и `docs` в существующую папку
   `pool-desktop`, соглашаясь на замену совпадающих файлов.
4. Запустите `start.bat` в той же папке.

Обновление содержит готовый JAR, исправленные исходники, ресурсы и отчёты.
Maven для его установки не нужен. Файлов `.env` и `database.properties`
в обновлении нет: ваша настройка порта 15433 сохраняется. SQL-скрипты и
данные базы не изменяются.
