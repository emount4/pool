## Условия проверки базы и интерфейса

Docker в среде проверки недоступен. Для JDBC использовался PostgreSQL 18.3
в PGlite 0.5.8 с TCP-адаптером и расширением `btree_gist`. Это выполнение
PostgreSQL в WebAssembly, а не запуск контейнера `postgres:16-alpine`.
Скрипты схемы, данных и миграции выполнялись на отдельной временной базе.
Интеграционные тесты создавали отдельную схему и удаляли только её.

Графические проверки выполнялись в JavaFX/Monocle в режиме headless.
Снимки реального JavaFX-интерфейса с учебными данными находятся в
`docs/screenshots/`; это не нарисованные макеты.

## Проверка готового архива

11 октября 2026 года завершена сборка профиля `portable`. Проверена
целостность ZIP и наличие JAR, ресурсов, конфигурации, исходников и
JavaFX-библиотек для Windows x64, Linux x64, macOS Intel и Apple Silicon.
Shell-скрипты проходят синтаксическую проверку и имеют право запуска в ZIP.

Из отдельно распакованной сборки выполнена дополнительная проверка
JavaFX/Monocle: открытие экрана входа, подключение по JDBC, вход `admin`,
загрузка четырёх вкладок и 20 посещений, применение CSS и отрисовка окна.
Использовались JAR и библиотеки именно из архива.
Результат: `PACKAGED_UI_OK`. Эта проверка дополняет 24 теста выше.

## Повторение тестов

```sh
./mvnw test
./mvnw -Pui-tests test
```

Обычный прогон без дополнительных настроек выполняет 18 модульных тестов.
Для JDBC задайте `POOL_TEST_DB_URL`, при необходимости `POOL_TEST_DB_USER`
и `POOL_TEST_DB_PASSWORD`. Для UI с данными дополнительно задайте
`POOL_UI_DB_URL` и используйте отдельную учебную БД с начальными данными
из этого проекта. Комбинация этих переменных и профиля `ui-tests` включает
все 24 теста. UI-профиль рассчитан на Linux.

## Границы проверки

- Docker Compose и первый запуск контейнера PostgreSQL 16 здесь не выполнялись.
- Нативные окна Windows и macOS здесь не запускались; в архив включены
  платформенные библиотеки JavaFX и соответствующие скрипты.
- Преподавательский архив Student Hub не был приложен, поэтому запуск его
  backend и web-части не проверялся. Собственный клиент «Бассейн» использует
  прямой JDBC согласно разделу ТЗ о собственной КР №2.
- Java 21, Docker Desktop и образ PostgreSQL устанавливаются отдельно.

Порядок локальной проверки и демонстрации приведён в `README.md` и
`docs/REQUIREMENTS.md`.
