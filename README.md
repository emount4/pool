# Информационная система «Бассейн»

Консольное Java-приложение для управления клиентами и посещениями бассейна.
Использует PostgreSQL, JDBC, роли `ADMIN`/`OPERATOR` и Excel-экспорт.

## Запись на посещение

- часы работы: `07:00–22:00`;
- начало посещения доступно каждые 30 минут;
- продолжительность выбирается от 30 до 180 минут с шагом 30 минут;
- приложение показывает только интервалы, свободные для клиента;
- занятая дорожка исключается из доступных вариантов;
- отменённые посещения не занимают время и дорожку.

## Запуск в Docker

Требуется Docker Desktop с поддержкой Docker Compose.

Собрать образ, запустить PostgreSQL и открыть интерактивное приложение:

```powershell
docker compose run --rm --build app
```

При следующих запусках сборка возьмётся из Docker-кэша.

Тестовые учётные записи:

```text
ADMIN:    admin / Admin123
OPERATOR: operator1 / Operator123
```

Excel-файлы сохраняются в локальный каталог `exports`.

Остановить контейнеры:

```powershell
docker compose down
```

Полностью пересоздать базу с начальными данными:

```powershell
docker compose down -v
docker compose up -d db
```

Команда `docker compose down -v` удаляет Docker-том вместе с данными базы.
Скрипты из `database/` выполняются автоматически только при создании нового тома.

Подключение к Docker-БД с хоста:

```text
host: localhost
port: 5433
database: pool_db
username: postgres
password: postgres
```

Пароль и внешний порт можно переопределить переменными окружения
`POSTGRES_PASSWORD` и `POSTGRES_PORT`.
